## Problem Overview

Defected Nuts is an unsupervised anomaly segmentation task, where participants must detect and precisely localize subtle defects in high-resolution images of hazelnuts. The dataset provides 431 defect-free training images and 70 test images containing various defects, including hairline cracks, tiny cuts, small holes, and machine-print contamination. The goal is to generate a precise pixel-level anomaly mask (heatmap) for each test image, despite having no defective training examples.

![Anomalous Nut](/assets/comparasion_nuts.JPG)

## Clarifying Constraints

The task statement strictly limits participants to using only a standard ResNet18 pretrained on ImageNet. No other models or external datasets are allowed.

## How can we define "Normal"?

Since we cannot train a model to recognize defects (we don't have any), we must take the opposite approach: learn exactly what a "normal" hazelnut looks like and flag anything that deviates.

Traditional approaches in unsupervized anomaly segmentation use Autoencoders. They train AEs to reconstruct normal images, assuming anomalies will produce higher reconstruction errors. However, overgeneralization of AEs will cause the defected samples of nuts to be reconstructed as normal

![Unsupervized Anomaly Segmentation](/assets/anomaly_ae.jpg)

Thus, reference solution uses feature-matching approach, comparing local image features to those of known normal patterns to identify anomalies more precisely.

## Feature Extraction from ResNet18

The reference solution uses the allowed ResNet18 as a fixed feature extractor. For every image, we pass it through network, and extract intermediate activation maps from the first three residual blocks `layer1`, `layer2`, `layer3`. These layers are preferable because they preserve fine-grained local and textural information needed to detect subtle defects.

The feature maps from these three layers are all bilinearly resized to a common spatial grid of layer3 height and width. By concatenating them along the channel dimension (64 + 128 + 256), we obtain a 448-dimensional vector for every single patch in that 128×128 grid:

```python
        sz = f3.shape[2:]
        f1 = F.interpolate(f1, size=sz, mode="bilinear", align_corners=False)
        f2 = F.interpolate(f2, size=sz, mode="bilinear", align_corners=False)
        return torch.cat([f1, f2, f3], dim=1)   # [B, 448, H', W']
```

## Solution A: Multi-Scale PatchCore

Across 431 training images, this generates roughly 1.7 million normal feature patches. To avoid massive memory and computation bottlenecks at inference time, we randomly sample a 10% "coreset" memory bank.
During inference, for every patch in the test image, we calculate the minimum $L_2$ distance to our normal memory bank. If a patch contains a defect, it will land far away from any normal patch in the feature space, yielding a high anomaly score.

![PathCore](/assets/patchcore.jpg)

```python
with torch.no_grad():
    for p in test_paths:
        feats   = extractor(load_image(p).to(DEVICE))
        patches = feats.permute(0, 2, 3, 1).reshape(-1, feats.shape[1])
        dists   = torch.cdist(patches, memory_bank).min(dim=1).values.cpu().numpy()
        score   = upsample_to_original(dists.reshape(feat_h, feat_w))
        anomaly_maps.append(gaussian_filter(score, sigma=SIGMA))
```

We use this distances as anomaly scores, upsample them to the original image dimensions (1028x1028) bilinearly and apply `gaussian_filter` to smooth them, reducing noisy, isolated pixel responses while preserving larger, consistent defect regions.

This simple non-parametric nearest-neighbor approach scores a massive 0.9735 AUPRO on the leaderboard. Read more about [PatchCore](https://arxiv.org/pdf/2106.08265)

## Solution B: EfficientAD

PatchCore is powerful but memory-bank queries can be slow, motivating a Student-Teacher architecture inspired by EfficientAD that encodes normal features directly into network weights.

The core idea is to train a lightweight "Student" network to perfectly mimic a frozen pretrained "Teacher" (our ResNet18), but only on normal images.

We also introduce an Autoencoder (AE) that compresses the Teacher's features into a tight bottleneck and tries to reconstruct them.

```python
for img_t in train_tensors:
    with torch.no_grad():
        t_feat = teacher(img_t) # Frozen Teacher

    s_feat  = student(t_feat.detach())           # Mimic directly
    ae_feat = decoder(encoder(t_feat.detach()))  # Compress and reconstruct

    loss = F.mse_loss(s_feat, t_feat.detach()) + F.mse_loss(ae_feat, t_feat.detach())
    
    loss.backward()
    optimizer.step()
```

Because the Student and AE are trained exclusively on perfect, defect-free nuts, they become highly specialized experts at reconstructing normal hazelnut.

When a test image containing a crack is fed into the system:
- The frozen Teacher extracts the true features of the crack.
- The Student and Autoencoder look at the image and attempt to output features, but because they have never seen a crack in their training data, their outputs will look like a normal hazelnut.
- A massive discrepancy occurs between the Teacher's features and the Student/AE's features at the exact spatial location of the crack.

We define anomaly score using:

$ \text{Anomaly Score} = \text{MSE}(F_{\text{student}}, F_{\text{teacher}}) + \text{MSE}(F_{\text{ae}}, F_{\text{teacher}}) $

By averaging the squared error across the channel dimension and scaling it up to 1024x1024, we obtain a pixel-wise anomaly map. This pushes the score even higher to 0.9763 AUPRO, while being extremely fast during inference. Read more about [EfficientAD](https://arxiv.org/pdf/2303.14535)

## Final Remarks

There are many methods that can be used to solve Unsupervized Anomaly Segmentation Tasks. In this editorial, we explored two SOTA methods: PatchCore, which uses distance-based approach to obtain anomaly scores and EfficientAD, which uses student-teacher inspired training. Unsupervised constraint forces us to find proxy tasks, making it one of the most creatively engaging domains in Computer Vision.
